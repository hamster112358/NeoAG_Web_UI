SOTA tool discovery & benchmarking

real retrieval

Live mode queries real public sources (Europe PMC, PubMed, OpenAlex, GitHub, PyPI, bio.tools) and the code-grounded inventory of the configured NeoAG repository. It verifies existence, version and license and quotes benchmark claims at abstract level - it does NOT execute or benchmark anything, and unverified fields stay Not verified. Example fixture mode is a fixed testing dataset, never real evidence.

Agent skills

advisory only

Skills are advisory instructions the agent loads at the start of a session. They cannot change the execution gate, the policies, the thresholds or the approvals - those live elsewhere and stay enforced. Deploying writes files into the agent workspace; only new agent sessions pick them up.
